## ✨ Ключевые возможности

### 🎨 Дизайн и интерфейс
- 🪟 **Liquid Glass & Acrylic Blur**: Настоящее аппаратное размытие рабочего стола Windows DWM (`dwmapi.dll`) позади окна с регулировкой прозрачности.
- 🖤 **Monochrome Cyber-Minimalism**: Чистая высококонтрастная черно-белая эстетика, плавная инверсия кнопок и векторные SVG-пиктограммы.
- 📐 **Идеальная геометрия (12-18px)**: Все окна (Главное, Настройки, История, Пакетная загрузка, Плейлисты) обладают аппаратным сглаживанием DWM без острых краев.

### 📥 Загрузка и форматы
- 🎬 **Ultra-HD Video (до 4K/8K 60fps)**: Скачивание видеопотоков в максимальном качестве с объединением через FFmpeg.
- 📑 **Умные плейлисты YouTube**: Распознавание ссылок на плейлисты с интерактивным окном выбора роликов чекбоксами.
- 💬 **Субтитры (.srt / .vtt)**: Автоматическое сохранение оригинальных субтитров и автоперевода (RU / EN).
- 🎵 **Hi-Res Audio Extractor**: Извлечение звука в **MP3 (320 kbps)**, **FLAC (Lossless)**, **M4A (AAC)**, **OPUS**, **WAV** с вшиванием ID3-тегов и обложки.
- 📱 **TikTok Без водяных знаков**: Оригинальные ролики без водяных знаков и логотипов.
- 📸 **Instagram Фото, Видео и Карусели**: Загрузка одиночных фотографий и роликов в максимальном качестве, а также многостраничных постов (каруселей) с интерактивным окном выбора снимков и видео ("ВЫБРАТЬ ВСЕ", превью, номера элементов).
- 🍪 **Импорт Cookies**: Авторизация через Chrome, Edge, Firefox, Brave, Opera, Яндекс для 18+ и приватных видео.
- 📦 **Универсальная очередь (Unified Queue)**: Пакетная загрузка смешанного списка интернет-ссылок и локальных файлов в одном интерфейсе с независимыми настройками для каждого элемента.

## 🚀 Установка и запуск

### Системные требования
- **ОС**: Windows 10 / Windows 11 (64-bit)
- **При запуске из исходников**: [FFmpeg](https://ffmpeg.org/) и FFprobe (для объединения потоков, нарезки, кадрирования и сжатия). В автономной сборке они уже включены.
  - *Способ 1 (через winget)*:
    ```bash
    winget install Gyan.FFmpeg
    ```
  - *Способ 2 (портативный)*: просто поместите `ffmpeg.exe` и `ffprobe.exe` в папку `tools/` рядом с программой — Aura Downloader автоматически обнаружит их без изменения системного PATH.
- **AI Интерполяция (RIFE)**: Любая современная видеокарта NVIDIA / AMD / Intel с поддержкой Vulkan API.

### Вариант 1: Готовая программа
Скачайте архив **AuraDownloader-…-windows-x64.zip** на [странице релизов](https://github.com/csezet/aura-downloader/releases/latest), распакуйте всю папку и запустите **AuraDownloader.exe**. Для новых сборок по этому сценарию Python, FFmpeg и Deno входят в дистрибутив. Сохраняйте папку `_internal/` рядом с EXE.

### Вариант 2: Сборка в автономный `.exe` (PyInstaller)
Для сборки готового дистрибутива `AuraDownloader.exe`, не требующего Python у конечного пользователя:
```bash
python -m pip install -r requirements-lock.txt
python build_exe.py --download-tools
```
Используйте **CPython 3.12.10 на Windows x64**. Готовый файл появится в `dist/AuraDownloader/AuraDownloader.exe`; архив и SHA-256 — в `dist/`. Сборка проверяет перенесённый EXE без системных Python/FFmpeg/Deno перед упаковкой. Подробности и ручные проверки: [подготовка выпуска](docs/RELEASE.md).

## 🔄 Обновления и диагностика
В новой EXE-сборке откройте **Настройки → Проверить обновления**. Приложение проверяет стабильные релизы этого репозитория и предлагает скачать новую Windows-сборку. Для обновления закройте программу и распакуйте новый архив в другую папку: настройки и история сохраняются в профиле пользователя. В исходниках кнопка обновляет yt-dlp вместе с JavaScript-компонентами; после обновления нужен перезапуск.

**Настройки → Журнал ошибок** открывает `%LOCALAPPDATA%/AuraDownloader/logs/`. Ошибки пишутся в файл и при запуске без консоли, с ротацией и маскированием URL/полей авторизации. При проблеме со сборкой используйте `dist/smoke-report.json`. Версия отображается в настройках; состав сборки записан в `build-manifest.json`. Лицензии компонентов описаны в [THIRD_PARTY.md](THIRD_PARTY.md).

## 🛡️ Сохранность данных
- Настройки и история находятся в `%USERPROFILE%/.aura_downloader/`. JSON сохраняется атомарно; рядом хранится резервная копия `.bak`. Повреждённый файл при исправлении сохраняется как `.corrupt`.
- Если выбранная папка загрузок недоступна, приложение выбирает доступную резервную папку и сообщает об этом в главном окне. Исходный путь остаётся в списке известных папок.
- Кеш превью находится в `%TEMP%/AuraDownloader/cache/`, в отдельном каталоге сессии. Очистка не удаляет пользовательские файлы по совпадению имени, включая `sample_*.mp4` и `aura_proxy_*.mp4`.
- Активные каталоги кеша и загрузок защищены межпроцессными блокировками. Завершённые файлы восстановления не удаляются автоматически. Старые временные файлы без служебной метки сохраняются для ручного разбора.

## 🧪 Проверки
Запускайте тесты из корня проекта через Python с установленными зависимостями:
```powershell
.\venv\Scripts\python.exe tests/run_tests.py
```
Если зависимости установлены в другом окружении, используйте его `python`. Скрипт запускает Qt без окон и изолирует настройки, историю и временные каталоги, не затрагивая пользовательские данные.

Тесты обработки требуют FFmpeg и FFprobe. Они создают короткие видео, проверяют кодеки, разрешение, FPS, длительность, звук, GIF, прямые загрузки и сохранность исходников. Для RIFE проверяются выбор модели, число кадров и сборка MP4 с имитацией нейросетевого движка; это не проверка качества интерполяции на реальном GPU.

## 🎞️ Параметры обработки
- Все результаты Local Studio сохраняются в выбранную папку загрузок; исходные файлы не изменяются. Прямые ссылки на видео также учитывают выбранные параметры обработки.
- Обрезка по времени, кадрирование и разрешение применяются перед изменением FPS. GIF и сжатие выполняются последними, чтобы готовый файл сохранял нужный формат и лимит размера.
- Разрешение вида `720p` ограничивает высоту, а `1280x720` — обе стороны. Пропорции сохраняются, увеличение маленького исходника не выполняется. Для локального видео доступны исходные размеры и меньшие варианты.
- Режим `2x` удваивает исходный FPS, включая дробные значения: `24000/1001 → 48000/1001`. После интерполяции создаётся MP4; звук сохраняется при наличии, видео без звука также поддерживается.
- При ошибке RIFE включается интерполяция движения FFmpeg. Если и она не работает, статус сообщает о резервном режиме с повторением кадров.
- В [документации RIFE](https://github.com/nihui/rife-ncnn-vulkan#full-usages) параметр `-n` означает число кадров всего ролика, а `-m` выбирает модель. Приложение рассчитывает число кадров по длине исходной последовательности и явно выбирает v4.6.

## 📋 Работа с очередью
1. Добавьте ссылку, перетащите видео или папку либо нажмите **ФАЙЛЫ**. Окно **ПАКЕТ** принимает ссылки и локальные пути, по одному на строку; оно добавляет карточки в главное окно.
2. Кликните карточку, чтобы настроить её. Формат, разрешение, отрезок, кадрирование и FPS отображаются под названием. Параметры разных карточек независимы; начальный аудиоформат берётся из настроек приложения.
3. Отметьте элементы флажками. Доступны **Выбрать все**, **Снять выбор** и **Применить к выбранным**. Последняя команда явно копирует параметры активной карточки; фотографии сохраняют оригинальный режим.
4. Нажмите **Запустить выбранные**. Локальные файлы, ссылки, плейлисты и галереи используют одну очередь. Выбор элементов галереи добавляет карточки и не запускает скачивание автоматически.
5. Следите за состоянием каждой карточки: загрузка, обработка, готово или ошибка. Готовый файл можно открыть кнопкой **▶**. Успешные элементы снимаются с выбора, чтобы следующий запуск не скачивал их повторно.
6. **Отмена** останавливает очередь и оставляет доступными готовые файлы. **Продолжить** запускает оставшиеся элементы. **Повторить сбои** повторяет только ошибки; обе команды сохраняют исходные параметры и папку сохранения.

Если размер или длительность сетевого видео ещё неизвестны, используйте **Уточнить данные видео**. Кадрирование и визуальный таймлайн доступны после получения нужных данных; время отрезка можно указать вручную. Неверные значения проверяются до запуска.

Горячие клавиши: **Ctrl+O** — добавить файлы, **Ctrl+B** — список источников, **Ctrl+L** — поле ссылки, **Ctrl+Enter** — запустить выбранные элементы. Очистка поля ссылки не удаляет очередь.
